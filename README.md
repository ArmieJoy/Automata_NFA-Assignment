## Assignment: Minimization of DFA
**Date:** 09/20/2026

### Description
This assignment demonstrates the process of **DFA Minimization** using the state equivalence theorem. 
It includes:
- Representation of the initial DFA Graph and its Transition Table
- Step-by-step state equivalence partitioning 
- The resulting Minimized Transition Table and Minimized DFA Graph
- Validation using sample inputs to verify accepted and rejected strings
